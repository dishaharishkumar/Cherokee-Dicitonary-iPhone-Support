Frequently Asked Questions

How do I install the Cherokee keyboard?

After downloading the app:

  1. Go to Settings > General > Keyboard > Keyboards
  2. Tap "Add New Keyboard"
  3. Select "Cherokee Dictionary"

Can I use the keyboard in other apps?

Yes! Once enabled, the Cherokee keyboard can be used in any iOS app that supports text input like Messages, Notes, Mail, etc.

How do I switch between keyboard modes?

Use the shift key to toggle between uppercase and lowercase Cherokee characters.

The keyboard isn't showing up. What should I do?

Try these steps:

  • Restart the app
  • Restart your iPhone
  • Re-add the keyboard in Settings

What iOS versions are supported?

The app requires iOS 14.0 or later.

Is the app available on Android?

Currently, the Cherokee Dictionary is only available for iOS devices. An Android version may be considered in the future.

How do I report a bug or suggest a feature?

You can contact us via email with bug reports or feature suggestions. We appreciate all feedback to improve the app.

Troubleshooting

App crashes or freezes

  • Force quit the app and reopen it
  • Restart your device
  • Check for app updates in the App Store
  • Ensure you have enough storage space

Characters not displaying correctly

  • Make sure your device supports Cherokee Unicode characters
  • Try adjusting the keyboard size using the zoom controls
  • Update to the latest iOS version
